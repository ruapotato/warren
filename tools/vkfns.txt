# Every Vulkan entry point Warren calls. Loaded at run time through
# vkGetInstanceProcAddr, so a machine with no Vulkan driver falls back
# to OpenGL instead of failing to start.
#
# Three scopes, because Vulkan resolves them from three different
# places and device-scope functions resolved from the instance go
# through a dispatch trampoline that costs a pointer chase per call.
