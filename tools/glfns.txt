#
# The loader is generated from this list against the Khronos header, so a
# typo is a build error rather than a null pointer at run time, and the
# list doubles as a statement of exactly how much of OpenGL the engine
# depends on. Everything here is core 4.5 -- direct state access, so no
# bind-to-edit anywhere in the renderer.
